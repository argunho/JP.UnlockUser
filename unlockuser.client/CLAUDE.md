# Project rules

- Always correct the user's English when they write a message in English (they are practicing the language).
- Always explain things in Russian, not English — the user understands Russian better.
- When writing or editing code in this project, mark every change with the current date/time:
  - For a multi-line change, wrap it:
    ```
    // start: <current datetime>
    ...changed code...
    // end
    ```
  - For a single-line change, append the datetime as a trailing comment on that same line instead:
    ```
    someCode(); // <current datetime>
    ```
